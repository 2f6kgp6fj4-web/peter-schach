# Schach mit Rokko

Schach lernen und am echten Brett gegen Rokko spielen, den freundlichen Schach-Roboter für Kinder ab fünf Jahren.

**Spielen:** Die Seite in Safari öffnen, dann *Teilen → Zum Home-Bildschirm*. Danach startet Rokko wie eine App und funktioniert auch ohne Internet.

Der Spielstand bleibt nur auf dem jeweiligen Gerät gespeichert. Keine Werbung, kein Tracking, kein Konto: [Datenschutz](datenschutz.html).
