Datenschutz

Schach mit Rokko · Stand: 29. Oktober 2026

Kurz gesagt: Schach mit Rokko sammelt keine persönlichen Daten, hat keine Werbung, kein Tracking, keine Analyse-Werkzeuge, kein Benutzerkonto und keine Käufe. Alles, was das Spiel speichert, bleibt auf dem Gerät.

Was gespeichert wird

Das Spiel speichert den Spielstand (Name des Kindes, Fortschritt, Sterne, Partien, Einstellungen) im lokalen Speicher des Geräts. Diese Daten verlassen das Gerät nicht und werden an niemanden übertragen. Eltern können den Spielstand im Elternbereich als Code sichern; diesen Code gibt nur der Nutzer selbst weiter.

Urkunden

Tippt man bei einer Urkunde auf „Sichern“ oder „Drucken“, erstellt das Spiel ein Bild auf dem Gerät. Wohin es geht (Fotos, Drucker, Nachricht), entscheidet der Nutzer im Teilen-Menü. In der iPhone-App fragt iOS beim ersten Speichern in die Fotos um Erlaubnis.

Mikrofon und Spracherkennung

Damit das Kind seine Züge ansagen kann, nutzt das Spiel das Mikrofon. In der iPhone-App erkennt die Spracherkennung von Apple die Sprache, wenn möglich direkt auf dem Gerät. Ist das nicht möglich, verarbeitet Apple die Aufnahme nach den Datenschutzbestimmungen von Apple. Schach mit Rokko selbst speichert keine Aufnahmen. Im Browser verwendet das Spiel die Spracherkennung des Browsers.

Verbindungen ins Internet

  • iPhone-App: keine. Das Spiel ist vollständig in der App enthalten.
  • Web-Version: Beim Aufruf lädt der Browser das Spiel von GitHub Pages (GitHub, Inc.). Dabei verarbeitet GitHub technisch die IP-Adresse, wie bei jedem Webseitenaufruf.
  • Natürliche Stimme (nur Web-Version, freiwillig): Tippen Eltern auf „Stimme laden“, lädt der Browser einmalig ein Sprachmodell von externen Servern (jsDelivr und Hugging Face). Danach läuft die Stimme offline auf dem Gerät.

Kinder

Das Spiel richtet sich an Kinder ab fünf Jahren. Einstellungen und Auswertungen sind durch eine Rechenaufgabe für Eltern geschützt. Es gibt keine Chats, keine Kontakte zu anderen Nutzern und keine Links nach außen im Kinderbereich.

Löschen

Den Spielstand löschen Eltern im Elternbereich unter „Fortschritt zurücksetzen“ oder indem sie die App beziehungsweise die Website-Daten im Browser löschen.
